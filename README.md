# 员工后勤餐补订餐管理系统
本项目是基于SpringBoot开发的企业内部后端管理系统，主要用于公司后勤餐补和订餐业务。
系统实现员工登录认证、餐补额度管理、菜品维护、在线订餐、订单记录查询等业务，使用Knife4j生成在线接口文档，方便前后端联调。

## 技术栈
SpringBoot 2.7.18
MyBatis-Plus
MySQL
Redis
JWT
Knife4j OpenAPI3
Maven

## 项目模块说明
1. 用户权限模块
   基于JWT实现登录鉴权，区分不同角色访问权限，接口请求携带token校验身份，防止未授权访问。

2. 员工与餐补模块
   维护员工基础信息，配置每个员工每月餐补额度，记录餐补使用、剩余额度。

3. 菜品管理模块
   管理员维护菜品信息，设置菜品上下架，供员工订餐时选择。

4. 订单模块
   员工可以在线提交订餐，生成订单；后台可以查看所有订单，统计订餐数据。

5. 接口文档模块
   集成Knife4j，自动扫描项目接口生成可视化API文档，开发调试直接访问页面测试接口。

## 项目启动步骤
1. 使用IDEA导入项目，等待Maven下载全部依赖。
2. 在本地MySQL创建数据库，执行docs文件夹下的建表SQL脚本。
3. 配置本地数据库与Redis信息：
   项目使用多环境配置，公共配置写在application.yml，本地账号密码放在application-local.yml。
   application-local.yml已配置在.gitignore，不会提交到代码仓库。
4. 运行项目启动类，启动成功后访问Knife4j文档地址：
   http://localhost:8080/doc.html

## 补充说明
- 项目做了全局统一返回结果封装，所有接口返回Result对象，包含code、message、data字段。
- 增加全局异常处理，捕获业务异常，返回标准化错误信息。
- JWT拦截器过滤请求，排除文档相关路径，保证文档页面正常访问。
